# 研究报告源文件

中文研究报告《AI 不设上限以后，社会如何完成过渡？》的生成代码与内容。

- `content.json`：章节、图表说明与来源。
- `visuals.py`：机制图与交互图的生成代码。
- `assets/`：报告的样式与阅读交互（目录、大字阅读、专注阅读、打印样式）。
- `build.py`：用 Python 标准库生成 `index.html` 和 `报告正文.md`。

一般不需要单独运行：在仓库根目录执行 `python3 build.py`，会同时生成中英文报告和首页。

报告采用 2026—2029 年的压力情景做机制推演，不把 AGI／ASI 的到来时间写成事实；图示表达条件关系，不包含虚构的量化预测；政策是待比较的选项；来源集中在附录。
